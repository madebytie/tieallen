# Tru's Distribution Playbook

The daily operating manual for the distribution engine. Several hours/day,
three workstreams. Everything Tie's voice requires stays with Tie — this
playbook is volume, consistency, and tracking.

---

## Workstream 1 — Job applications (daily, first priority)

- Source boards: **Wellfound** (primary — founders read these themselves) ·
  LinkedIn · We Work Remotely · others as found
- **Freshness rule: only postings <48h old.** An early application to a fresh
  posting beats ten to stale ones.
- **Which resume:** job title says Founding Designer / seed-stage startup /
  founder is the recruiter → `tie-love-resume.pdf`. Title says Lead/Senior/
  Staff/Principal Product Designer or a recruiter/talent team runs it →
  `tie-love-resume-product-leadership.pdf`. Ambiguous → founding.
- **Skip:** roles whose process/JD demands coding challenges or reads
  engineer-first (identity rule — Tie builds with AI, doesn't do take-homes).
- Wellfound profile copy already written (bio, "looking for," achievements) —
  reuse phrasing in application answers; keep the warm tone, no swagger.
- Flag postings where a founder is directly reachable → Tie replies personally
  on X/LinkedIn instead of (or in addition to) the form.

## Workstream 2 — Scope Architect directory submissions (5–10/day)

Target list + copy bank: [launch-scope-architect.md](./launch-scope-architect.md)
§2 + §4. Work the tiers top down. Every form wants the same five things —
tagline, short description, long description, logo, screenshots — all
pre-written in the copy bank; paste, don't improvise claims.

## Workstream 3 — LoreTorch micro-influencer outreach (5–10 first-touches/day)

List-building: D&D/TTRPG YouTube + TikTok creators, ~5k–100k followers,
priority to solo-RPG / "can't find a group" content. Log every prospect in the
tracker before first touch.

**First-touch template (DM or email — personalize the first line, always):**
> Hey [name] — [one genuine line about their specific video/content]. My
> husband built LoreTorch: a virtual tabletop with an AI game master (Aris)
> that runs full D&D 5E sessions solo, zero prep. We'd love to give you free
> full access to break it however you like. No strings — if it's fun, tell
> your audience; if it's not, tell us why. — Tru

Any reply → hand the conversation to Tie same day.

---

## The tracker (keep one sheet, three tabs)

| Tab | Columns |
|-----|---------|
| Applications | date · company · role · board · resume sent · status · follow-up date |
| Directories | date · site · product · status (submitted/live/rejected) · URL |
| Influencers | name · platform · followers · niche · date touched · response · owner |

Follow-up rhythm: applications +5 days if no response (once) · influencers +7
days (once) · directories don't chase.

## Boundaries (what stays with Tie)

Anything published in his voice (posts, comments, HN/PH threads) · pricing or
scope conversations · interviews and calls · any reply requiring product
depth. When in doubt: log it, flag it, don't send it.
